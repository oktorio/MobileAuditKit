# OWASP Mapping Notes

MobileAuditKit uses OWASP Mobile Top 10 2024 as a high-level risk taxonomy and OWASP MASVS/MASWE/MASTG for control and testing references.

MASVS v2 does not use the legacy L1/L2/R verification levels as MASVS controls. OWASP checklists may still expose transition/testing-profile information. The packaged mapping YAML files are dated and deliberately limited to IDs relevant to implemented modules.

Do not interpret a mapping as automatic compliance or a final vulnerability conclusion. Test status and identifiers should be revalidated against the current OWASP MAS project when mappings are updated.
